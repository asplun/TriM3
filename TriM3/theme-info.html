v1.2.10 更新内容

  • 匿名图片加载修复：修复 CDN 缓存到空懒加载脚本后图片不显示，增加视口附近图片补扫。
  • 移动音乐页适配：播放器独占手机视口，底栏、歌单滚动和播放视图返回按钮适配移动端。
  • 音乐与缓存修复：修复腾讯歌单播放次数、图片缓存待处理统计和设置持久化问题。
  • 搜索导航修复：搜索改为 Swup 无刷新切换，播放器跨页保持。
  • 安全加固：图片代理去除硬编码表名并收紧开放重定向；音乐 API CORS 改为同源；CSRF 校验升级为完整 Origin 对比；相册上传增加真实图片内容校验
  • 性能优化：数据库自检标记改为优先读取 tri3DbInit，减少每请求查询；清理 4 个无引用旧构建产物，发布包体积进一步下降
  • 友链截图修复：18 张网站截图改为首屏直载，真实背景全部加载成功，不再停留在占位图
  • 代码门禁：新增 tools/code-gate.sh，覆盖 PHP 语法、危险调用、调试输出、备份文件、安全模式和旧资源检查

修复项

  • 修复友链页网站截图背景停留在占位图、无法显示真实截图的问题
  • 修复图片代理在非白名单域名上可能形成开放重定向的问题
  • 修复音乐 API 使用 * CORS 导致任意站点可消耗代理流量的问题
  • 修复CSRF 仅比较 Host、未校验协议和端口的问题
  • 修复相册上传仅校验扩展名、未校验真实图片内容的问题
  • 修复数据库自检每次请求都额外查询 options 表的问题

环境要求

  • Typecho 1.3+
  • PHP 7.4+（推荐 8.5）
  • 必需插件：TriM3Core（后台编辑器资源与核心 API 依赖）

安装

  • 解压到 usr/themes/ 目录，保证目录名为 TriM3
  • 后台「控制台 → 外观」启用 TriM3
  • 在「设置外观」中按需配置
  • 升级后请硬刷新 Ctrl+F5，避免旧静态资源缓存
