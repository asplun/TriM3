# TriM3 v1.2.10
安装包下载：<https://github.com/asplun/TriM3/releases/download/v1.2.10/TriM3-1.2.10.zip>

## 主题特色

- Material Design 3 三栏响应式布局
- Swup 全站无刷新导航
- 动态取色与深色模式
- 说说、相册、友链、豆瓣、番剧
- macOS 风格代码高亮
- lightgallery 全站灯箱
- 图片代理缓存与懒加载
- 后台可视化配置

## v1.2.10 更新内容

- 修复匿名访客缓存到 0 字节懒加载脚本后图片不显示，增加视口附近图片补扫。
- 完成移动音乐页视口独占、底部控制栏、播放视图返回和全局导航隔离。
- 修复腾讯歌单播放次数、图片缓存统计、主题设置持久化和 Swup 搜索导航。
- 主题发行版本统一为 `1.2.10`，安装包为 `TriM3-1.2.10.zip`。

## v1.2.9 更新内容

- 修复腾讯歌单播放次数、图片缓存统计、主题设置持久化和 Swup 搜索导航。

## 修复项

- 友链截图背景加载成功后自动恢复显示
- 图片代理非白名单域名不再开放重定向
- 音乐 API CORS 收紧为同源
- CSRF 校验升级为完整 Origin 对比
- 相册上传增加真实图片内容校验
- 数据库自检减少每请求额外查询

## 环境要求

- Typecho 1.3+
- PHP 7.4+（推荐 8.5）
- 必需插件：TriM3Core
