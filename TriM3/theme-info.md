# TriM3 v1.2.5

## 主题特色

- Material Design 3 三栏响应式布局
- Swup 全站无刷新导航
- 动态取色与深色模式
- 说说、相册、友链、豆瓣、番剧
- macOS 风格代码高亮
- lightgallery 全站灯箱
- 图片代理缓存与懒加载
- 后台可视化配置

## v1.2.5 更新内容

- 全站版本号统一为 `1.2.5`
- 安全加固：图片代理、音乐 API CORS、CSRF、相册上传校验
- 性能优化：数据库自检标记、清理旧构建产物
- 修复友链页网站截图背景加载问题，18 张截图改为首屏直载并全部验证通过
- 新增代码门禁脚本 `tools/code-gate.sh`

## 修复项

- 友链截图背景加载成功后自动恢复显示
- 图片代理非白名单域名不再开放重定向
- 音乐 API CORS 收紧为同源
- CSRF 校验升级为完整 Origin 对比
- 相册上传增加真实图片内容校验
- 数据库自检减少每请求额外查询

## 环境要求

- Typecho 1.3+
- PHP 7.4+（推荐 8.5）
- 必需插件：TriM3Core
